# Out of Asia
Out of Asia is a new game that is fun, nice, charming and is a Japanese role-playing game (JRPG)!
Yep, that's right. The game stars a gang of Asians called **The Mystery 3**. The leader is from Tokyo, JPN, the one who has the most effective powers is from Beijing, CHN, and the most curious one is from... \*drumroll\* Seoul, KOR. There are SEVERAL versions of the game (starting from The Journey Begins!! - v1.01.0)
And the game is almost like [the Old Prodigy Definitive Edition](https://oldprodigy.onrender.com/play/). Yep, it has a math function (**MATH TIME!!**), a chat function (chatters aren't quitters!), a mailing system (special delivery!), holiday events (Happy Holidays!), and... walking speed configuration (fast or slow?).
